# Speakify Logo Redesign — Design Spec

**Date:** 2026-07-17  
**Topic:** App icon redesign  
**Selected design:** H — Mic Pulse（麦声波）

---

## 1. Goal

Replace the current Speakify macOS app icon (`Sources/Speakify/Resources/AppIcon.icns`) with a new design that better represents the app as a text-to-speech / English-listening tool, while moving away from the ElevenLabs-specific "11" waveform reference in the existing icon.

## 2. Design Direction

The chosen design is **H — Mic Pulse**：a refined microphone icon centered on a dark rounded-square background, with glowing sound-wave arcs radiating from both sides.

This design communicates:
- **Voice / speech** — the microphone is the most universally recognized symbol for audio and speech.
- **Audio output** — the green arcs on each side read as sound waves, reinforcing the TTS output.
- **Professional macOS tool** — the dark background, subtle gradients, and soft glow fit the macOS desktop aesthetic without being overly playful or abstract.

## 3. Visual Specification

### 3.1 Canvas
- Standard macOS app icon canvas: **1024×1024 px**.
- Exported icon set via `Scripts/generate-icon.swift` at sizes: 16, 32, 128, 256, 512 (and @2x variants).
- Final asset: `Sources/Speakify/Resources/AppIcon.icns`.

### 3.2 Background
- Rounded-square shape with macOS-standard corner radius (≈214 px on 1024 px canvas).
- Dark gradient: top `#374151` → bottom `#111827` (slate/gray to near-black).
- Subtle inner highlight stroke: white at 8% opacity, 2 px width.
- Soft drop shadow below the icon for depth.

### 3.3 Microphone
- Stylized microphone in the center.
- Body: vertical rounded-rectangle capsule, gradient from `#E5E7EB` (top) to `#9CA3AF` (bottom).
- U-shaped cradle / stand: white/silver, 24 px stroke, rounded caps.
- Vertical stem and base: matching white/silver.
- Drop shadow for depth.

### 3.4 Sound Waves
- Two sets of curved arcs on each side of the microphone.
- Color: `#34D399` (emerald green) with a soft glow.
- Stroke width: 12 px, rounded caps.
- Opacity gradient: inner arcs at 90%, outer arcs at 60%.
- The arcs are positioned symmetrically left and right of the microphone body.

## 4. Implementation Approach

The project already uses a programmatic icon generator (`Scripts/generate-icon.swift`). The new icon will be implemented by **rewriting this generator** to draw the Mic Pulse design instead of the old waveform-core design.

### Why program generation instead of static files?
- It matches the existing workflow.
- It makes future icon tweaks trivial (change code, run script).
- It avoids storing large raster source files in git.

### Files to modify
1. `Scripts/generate-icon.swift` — replace drawing logic with the Mic Pulse design.
2. `Sources/Speakify/Resources/AppIcon.icns` — regenerated by the script.

### Files NOT affected
- `Package.swift` — resources processing remains unchanged.
- `Scripts/package-app.sh` — continues to copy the generated `.icns` into the `.app` bundle.
- App source code — no code changes beyond the icon asset.

## 5. Acceptance Criteria

- [ ] `Scripts/generate-icon.swift` produces the Mic Pulse icon at all required icon sizes.
- [ ] `Sources/Speakify/Resources/AppIcon.icns` is replaced with the new asset.
- [ ] Running `Scripts/package-app.sh` succeeds and the built `Speakify.app` shows the new icon in Finder and Launchpad.
- [ ] The icon remains visually clear at both 16×16 and 1024×1024 sizes.
- [ ] Git diff is reviewed: no unintended source-code changes.

## 6. Risks & Considerations

- **Small-size legibility:** The microphone and arcs must remain distinguishable at 16×16 and 32×32. This may require slightly thicker strokes or simplified arcs at tiny sizes.
- **Dark-mode compatibility:** The dark background works well on both light and dark wallpapers / menu bars.
- **Color accessibility:** The emerald green arcs on the dark background provide sufficient contrast.
- **Future provider additions:** If the app later supports multiple TTS providers, the microphone is provider-neutral.
